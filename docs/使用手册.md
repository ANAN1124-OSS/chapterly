# 章回 · 使用手册

> 面向使用者：从建书、导入、写作到导出整理的完整操作说明。第一次用请先看 [README](../README.md) 的三步开始。

## 怎么用

| 操作 | 方式 |
|---|---|
| 新建书 | 书架 →「＋ 新建一本书」 |
| 导入小说 | 书架右上「导入小说」，选一个或多个文件夹。先选导入方式：**按原文章节导入（默认）——按原文的「第X章 / 第X幕 / 第X话 / 楔子 / 番外 / 后记 / 附录」等标题拆成多章，章名照抄原文、正文一字不改（支持上百字的长标题和奇怪标点写法）**；或「整本一章」——不拆章，整本放在一章「全文」里（UTF-8 源文件按字节原样复制）。三种来源自动识别：① 章回书（含 `书目.json`）整本复制；② 一本书的章节目录（txt 名如 `001-xxx.txt`）合成一本书；③ 一堆独立小说 txt（一个放满小说 txt 的文件夹）→ 每个 txt 一本书。自动识别 UTF-8 / UTF-16 / GBK 编码；只复制不移动源文件；重名自动加 `-2`；大批量导入显示进度；**没有任何章节标题且超过 6 万字的长文会自动按段落切片**（约 5 万字一段，章名「第 1 部分 / 第 2 部分…」，正文一字不改） |
| 删除小说 | 鼠标移到书卡右上角「⋯」→「删除这本书…」，或右键书卡 → 删除。整本书移到 Windows 回收站（回收站不可用时移到书架 `_trash`），不会真删 |
| 打开书 | 点书卡；如果 `书目.json` 损坏，卡片会标红并提供修复 |
| 书籍信息（作者 / 简介 / 分组 / 标签） | 书架右键书卡（或右上角「⋯」）→「书籍信息…」：可以填作者、分组、标签（逗号 / 顿号分隔，最多 10 个）和简介（可多行）。保存后书卡会显示「作者：…」「分组：… · #标签」和两行简介；书架上方出现**分组 / 标签筛选**（两个下拉，选项带计数：全部分组（N）/ 未分组（N）/ 各组（N）、全部标签（N）/ #标签（N）；两者与搜索词一起按 AND 生效）。点筛选条右侧的**「管理分组…」**可以给分组**改名 / 合并**（大小写与首尾空白归一，能对上已有分组就并进去；目标留空 = 移到未分组），书卡右键还有**「移到分组…」**：点开在菜单里直接选已有分组（每项带「· N 本」、当前分组打勾，末尾还有「未分组」和「新建分组…」），选完只改这一本；分组按名字排序、不另存顺序，改名 / 合并只写每本书的 `书目.json` 的 group，书签与「继续上次写作」不受影响。书架搜索也能按作者 / 分组 / 标签命中。**只写这本书的 `书目.json`（可选字段），不改书文件夹名、不动任何章节 txt**；留空保存 = 清掉该字段。旧书没有这些字段照常打开、不会自动补 |
| 多窗口（同时开两本书） | 书架书卡右键 →「在新窗口打开」：新开一个窗口并直接打开这本书，原窗口留在书架（原来的**双击 / 回车在当前窗口打开**不变）。**同一本书不会开两个窗口**：这本书已经在某个窗口打开时，再点「在新窗口打开」只会**把那个窗口聚焦到前面**并提示，不会新建。两个窗口各开一本，可以各自编辑 / 保存 / 切章，互不干扰；关掉其中一个只关这个窗口（有未保存修改时照常弹「保存 / 不保存 / 取消」，且只问这个窗口），**只有最后一个窗口关闭时才退出应用**。书架数据一变（新建 / 删除 / 导入 / 保存 / 整理），**正停在书架的其它窗口会自动刷新**；写作页里的窗口不打断你，回书架时刷新。窗口位置 / 大小和「继续上次写作」都按**最近使用的窗口**算 |
| 同步冲突副本提示 | 书架目录放在 OneDrive / 坚果云里时，同步盘可能生成 `*conflicted*` / `*冲突副本*` 文件。书卡会标黄「⚠ 检测到同步冲突副本（N 个）」，点一下看文件名、并可「打开书文件夹」手动处理。写作器**只提示，不自动合并、不删除**；这些副本也不会出现在章节列表里 |
| 本书历史 | 写作页「导出 ▾ → 本书历史…」或右键书卡 →「本书历史…」：把书内 `_trash` 的**替换 / 整理 / 还原前 / 每日快照 / 删除章节**备份和书文件夹里的上一版 `书目.json.bak` 按时间新→旧列出来，并标出每个文件**还在不在书里**。可以**预览**、**还原单章**、**还原整组**：只还原现在仍在书里的章节（已删章节不会偷偷复活），还原前先把当前内容备份到 `_trash\还原前备份-时间戳\`（**1.4.0 起还原不再弹二次确认**，直接还原，左下角撤销条 10 秒内可用这份还原前备份撤回）。**每日快照按天折叠**（组头是可点的按钮、写着日期 / 文件数 / 大小，默认收起；其它备份组照旧默认展开，且折叠时不让整组还原）；快照组还有**「清空这天的快照」**：直接（**1.4.0 起不再二次确认**）只把那一个 `快照-YYYYMMDD` 目录**移入 Windows 回收站**（可从回收站恢复，不影响其它备份），回收站不可用就报错返回、一个文件都不动。删除的章节可以一键**放回书文件夹**（不自动加回章节列表、同名文件不覆盖）；书目备份只供查看，不提供覆盖还原 |
| 可选每日快照 | 「设置 → 数据安全」里打开（**默认关**）+ 选保留天数（1–90 天，默认 7）。开启后每次 `Ctrl+S` **成功保存**时，当天第一次保存会把这一章的**上一版**复制到书内 `_trash\快照-YYYYMMDD\`（同一章当天只留第一份，不重复、不覆盖）；保存时顺手清理超过保留天数的「快照-YYYYMMDD」目录，**只清理应用自己生成的快照目录**，不认识的目录 / 散文件一律不动。快照可在「本书历史」里预览、还原单章/整组。**这不是自动保存**：正文仍然只在你按保存时才写盘 |
| 可选崩溃恢复草稿 | 「设置 → 数据安全」里打开（**默认关**）。**这不是自动保存**：开启后写作页有未保存修改时每 30 秒把**编辑区正文**写进 `%APPDATA%\chapter-writer\crash-drafts\`（原子写、最多 8 份、超过 7 天自动清理），**只写应用配置目录，绝不写书库 / `书目.json` / 章节 txt / `config.json`**；界面崩溃或渲染进程崩溃重载后启动时弹一次「恢复 / 丢弃 / 先留着」：恢复只把正文放进编辑区（仍是未保存状态，`Ctrl+S` 才写盘），当前编辑区已有未保存修改时不覆盖。干净退出会清掉标记与草稿；目录不可写只吞掉错误，不影响保存。默认关时一个字节都不写 |
| 每日字数统计 + 写作目标 + 码字日历 | 书架顶部显示「今天 +N 字」和「连续 N 天」，写作页状态栏显示「今日 N 字」。**只统计按保存（`Ctrl+S` / 建章前自动保存）时新增的正字数**：没保存的编辑不算，删字也不会倒扣当天进度。想设目标就去书架 →「设置 → 写作统计」填每日目标（0 = 不设目标，默认关）：状态栏会出现一条细进度条，书架也会显示目标和完成百分比，达标后标「已达标」。设置里还有**近 30 天柱状图**、**码字日历**（周一开头，可翻看上个月 / 上上个月；颜色越深当天写得越多，绿点 = 当天达标，深色描边 = 今天）、**连续写作天数**（今天写了从今天往前数；今天还没写就从昨天往前数，当天结束前不算断）和**月度汇总**（本月合计 / 写字天数 / 日均 / 达标天数 / 最高一天）。设置里还有**累计汇总**：可选**某本书 / 某一年**（叠加也行）看总字数、写作天数、日均和覆盖几个月，并「生成 CSV」（UTF-8 BOM + 按天一行 + 末行合计，生成在只读文本框里，全选复制后存成 `.csv` 用 Excel / WPS 打开不乱码；本版不直接写盘）。统计数据只存在 `%APPDATA%\chapter-writer\stats.json`，日历和连续天数都从这份统计现算、不另存文件，不进书库、不改 `书目.json` / 章节 txt |
| 写作时长（可选，默认关） | 书架 →「设置 → 写作统计」勾选「记录写作时长」后，写作页状态栏出现「⏱ 写作计时」按钮：**点一下开始、再点暂停**，按钮上显示本次秒表；暂停 / 按保存 / 每 30 秒自动把整秒记进 `stats.json`，**回书架 / 换书 / 关窗会自动停表并记下**。设置里和码字日历下面会显示「今天写作 N 秒 / N 分钟 · 近 30 天 …」，日历格子悬浮也能看到当天用时。**只记时长、不记内容**（不读正文、不记按键），不做番茄钟倒计时 / 提醒；时长按天合计，不按书分开（切章不停表，换书 / 回书架才停） |
| 搜索书架 | 书架右上搜索框（或按 `Ctrl+F`）：书名 / 文件夹名 / **作者 / 分组 / 标签** / 章节名**输入即过滤（停手约 0.25 秒后刷新，连续输入不卡）**；**同时会搜正文**（索引在 `%APPDATA%\chapter-writer\search-index.json`，不进书库），命中结果在书卡上方以「正文命中」列出：按「书 + 章」分组，组头写「书名 · 第N章：章名 · 本章 N 处」（单章命中数数到上限时显示 `N+`），下面是带关键词高亮的上下文片段，点一条直接打开那一章并选中命中位置。正文结果默认先显示 8 条，「显示更多」可继续展开；默认每章只列 3 处，章内还有没列出的命中时点「展开本章全部」就地列出该章全部命中（单章最多 200 条，更多会标「只列出前 N 处」），再点「收起」恢复；整次最多 40 条（多了会标「只查了最近的一部分书」）。章名命中的书卡会显示「章节命中：第N章：xxx」，**每个章名都能单独点**，直接打开这本书并定位到那一章（`Tab` 可到、`Enter` / 空格同样；书卡其它位置仍按原行为打开上次章节）；`Enter` 打开第一本匹配的书（书名没命中时打开第一条正文命中），`Esc` 清空。正文搜索至少 **2 个字**；首次打开书架会在后台为整个书架建索引（界面上有进度提示），建好后自动增量更新，作者不用手动操作。分组筛选（书架上方下拉）可以和搜索叠加使用 |
| 新建章节 | 左栏底部「＋ 新建章节」，输入章节名（可留空：左栏只显示章号，章节文件按「未命名」命名）。**建章前如果当前章有未保存修改，会自动先保存当前章**（不弹窗；保存失败就停下报错，不会带着没存的内容建新章）。如果设置里填了**章节模板**，新章会自动套用（见下一行） |
| 章节模板 | 书架 →「设置 → 新建章节」填一段模板文字（默认空 = 不套用），新建 / 插入章节时会自动填进空章。可用占位符 **`{n}` 章号**、**`{title}` 章名**、**`{date}` 今天（YYYY-MM-DD）**，不认识的占位符原样保留；设置里有展开预览。套用后**只改编辑区**（状态栏显示「未保存」），`Ctrl+S` 才写盘、`Ctrl+Z` 可撤销；已有正文的章节不会被套模板，也不会动 `书目.json` / 章节文件名。导出 TXT / EPUB / DOCX 本来就会加章节标题，模板里再写「第{n}章：」会重复，按需使用 |
| 在中间插入 | 当前章标题栏「＋ 插入」，或章节右键 → 在此前/后插入。同样会先自动保存当前章 |
| 切换章节 | 单击左栏章节；有未保存修改时会弹窗 |
| 章节多选 + 批量动作（1.5.0） | 单击仍是切章；**Ctrl+单击**切换这一章选中、**Shift+单击**从上次点的那一章连选到这一章（都不切章），焦点在列表里按 `Ctrl+Space` 切换这一章、`Shift+↑/↓` 从锚点扩选（并集，不切章）、`Ctrl+A` 全选目录里看得见的章（焦点在正文 / 输入框时仍是原生全选）；批量条上的「已选 N 章」会即时播报给读屏软件。点列表空白、或没有弹层 / 菜单开着时按 `Esc` 清空多选。选中 ≥1 章时左栏底部出现一条 32px 批量条：**复制 / 导出 / 状态 / 移卷 / 删除 / 清除**。**删除**一次处理全部选中章（只有当前章本身有未保存内容时问一次），**一条撤销**按原位置把全部章放回；**移到卷**一次移全部、一条撤销全部移回；**改状态**逐章写 `书目.json`（不做撤销）；**导出只支持连续范围**（跳选会明确提示，不会静默扩大成别的范围）；**复制**按目录顺序（不是点击顺序）拼「标题 + 空行 + 正文」一次写剪贴板，当前章未保存时用编辑区文本。**右键落在已选章上**时，菜单里的状态 / 移到卷 / 删除作用于全部已选章（重命名 / 插入 / 备注 / 复制本章这类单章动作在批量菜单里收起）。多选只记内存、不写配置；换书 / 普通单击切章 / 点空白都清空；**不改正文、章节文件名，删除只进本书 `_trash`** |
| 继续上次写作 | 书架顶部会显示「继续写《书名》· 第N章」，点一下直接打开那本书并回到上次编辑的章节（记录在配置文件的 `lastBook` 里；打开书后仍以书内 `书目.json` 的 `lastOpenChapterId` 为准）。上次那本书被删掉、改名到书架外或损坏时，入口自动隐藏；只记最近一本 |
| 快速跳章 | 写作页按 `Ctrl+G`：输入章号（`12`、`第12章`、`12章`，全角数字也认）直接跳到第 12 章；或输入章名的一部分（如「夜雨」）列出匹配章节，点一条或回车跳第一条。章号超出范围会提示「本书共 N 章」；**按卷编号时输入纯数字会把各卷同号章都列出来（带卷名）**；跳章只切换章节、不改正文，有未保存内容时照常问「保存 / 不保存 / 取消」 |
| 拖拽排序章节 | 左栏**按住章节上下拖动**，松手即改顺序；只改 `书目.json` 数组顺序，**章节文件永不重命名**，章号按新顺序自动重算。拖到列表顶/底会自动滚动 |
| 分卷 | 侧栏底部「＋ 新建卷」建卷；卷在章节列表里显示成**可折叠的分组**。右键卷：重命名卷 / 在此卷末尾新建章节 / 删除卷（卷里的章回「未分卷」，**不删章、不动文件**）。右键章节 →「移到卷…」**就在同一个菜单里展开卷列表**（1.4.0 起不再弹选择框），选一个即移到那一卷或移回未分卷。**章节可以直接拖到别的卷**（拖到卷标题上 = 放进那一卷，拖到某章上 = 插到它前/后）；**焦点在章节列表时 `Alt+↑` / `Alt+↓` 到卷边界再按一次会跨到相邻的那一卷**（卷尾 ↓ = 下一卷卷首、卷首 ↑ = 上一卷卷尾，跨卷**不再弹确认框**（1.4.0 起直接挪、左下角撤销条 10 秒内可撤回）；一次只跨一个卷、空卷也算一步，未分卷不参与）；卷右键还能**上移卷 / 下移卷**调整卷序。**章号按这本书的编号方式**（默认全书连续；按卷编号时卷内从第 1 章起；导出范围输入与书架「正文命中」仍按全书顺序，见 [已知限制](docs/已知限制.md)）。导入的原文分卷会自动带进来；导出 / 复制时每卷前多一行卷名；「导出 TXT…」「导出 EPUB…」「导出 DOCX…」都能**按卷导出**（文件名默认 `书名-卷名.txt` / `书名-卷名.epub` / `书名-卷名.docx`） |
| 章节状态 + 备注 | 每章名字前有一个**状态小圆点**：灰 = 草稿（默认）、黄 = 待修、绿 = 完稿。右键章节 →「标记为完稿 / 待修 / 草稿」；右键 →「编辑备注…」写一句话（最多 200 字，悬浮章节可看）。书卡上会显示「完稿 X/Y 章」。**只写 `书目.json`，正文 txt 一个字节不动**；没标记过的章默认显示灰点，书目里也不会多出字段 |

## 查找替换与章节排序

**查找替换**（右上「查找」或 `Ctrl+F`）—— **字面量**查找，不搞正则（`.*` 就只是三个字符），避免误伤全稿：

- 范围「当前这一章」：只算编辑区，不写盘；替换只改编辑区（未保存），`Ctrl+Z` 可撤销。
- **上一处 / 下一处 + 结果持续高亮**（`v0.8-11`）：当前章查找后，本章**所有命中**都在正文上用淡琥珀底色高亮、正在看的那一处颜色更重；面板里「↑ 上一处 / ↓ 下一处」、查找框里 `Enter` / `Shift+Enter`、关掉面板后 `F3` / `Shift+F3` 都能前后跳（到末尾 / 开头会绕回，摘要里会说明），状态栏的「查找 3/12」小标签点一下也是下一处。`Esc` 清除高亮。高亮**只跟着这一次查找**：改正文、改查找词、改大小写 / 范围、切章、回书架或离开写作页就自动结束；不写配置、不写书库、不改正文。命中太多（超过 **500 处**）时正文里只高亮**当前附近的一屏**（导航仍对全部命中有效，单章上限 5000 处），摘要会说明。
- **从整本查找跳进某一章**时，那一章的命中也会自动全部高亮，接着按 `F3` 继续跳。
- **「替换这一处」**（只用于当前章）：只替换光标处的这一处，替换完自动选中下一处，可以连续按；改的只是编辑区，`Ctrl+S` 才写盘。整本范围下这个按钮不执行，避免误以为只改一处。
- 范围「整本书」：点「查找」列出命中的章节和上下文片段，点一条就跳到那一章并选中第一处。
- 「全部替换（整本）」：**先弹确认**（几章、几处），确认后才写盘；写盘前把改动的原章节**备份到书内 `_trash\替换备份-YYYYMMDD-HHMMSS\`**。
- **整本替换点错了可以退**：替换后打开「查找」面板，下方会出现「最近一次整本替换的备份」→ 点「还原到替换前…」，二次确认后把备份覆盖回书里；并且还原前会先把**当前内容**再备份一份到 `_trash\还原前备份-时间戳\`（所以还原这一步也能回头）。只还原最近一次替换；更早的备份在 `_trash` 里可手动拷回。
- 整本替换前如果有未保存的修改，会先问「保存 / 不保存 / 取消」，不会静默丢掉。

**章节拖拽排序**：

- 左栏按住章节上下拖动，松手生效；拖到最上面/最下面会自动滚动。
- 只改 `书目.json` 的顺序：**章节文件不移动、不改名**，内容和文件名的对应关系不变。
- 显示章号（第N章）按新顺序现算，所以拖完章号会自动重排。


## 整理与显示（写作页右上「整理 ▾」/「显示 ▾」）

排版功能参照同类写作软件常见的「排版设置」补齐：智能排版（文字级）+ 字体 / 间距 / 背景（显示级），两半互不干扰。v0.8.5 起顶栏拆成两个按钮：**「整理 ▾」管文字**（点一下直接整理本章，悬浮出选择卡），**「显示 ▾」管显示**（点一下展开菜单）。

**1. 智能排版（改 txt 内容，仅当前章）** —— **点「整理 ▾」就直接整理当前这一章**（用上次记住的规则，不弹窗）；想改规则就从悬浮选择卡进「排版设置…」：

| 选项 | 默认 | 说明 |
|---|---|---|
| 段首缩进 | 缩进 2 字符 | 三选：**缩进 2 字符**（先去掉原有行首空白，再统一加两个全角空格 `　　`）/ **缩进 0 字符**（只去掉缩进）/ **不处理缩进**（保留原样） |
| 段落之间 | 空一行 | 四选：保持原样 / 空一行 / **空一行（含缩进）** / 不空行（紧凑）。**所有模式都会丢掉正文开头的空行、结尾连续空行只保留一个**；「保持原样」保持的是段与段之间的空行数 |
| 删除每行行尾空白 | 开 | 只删行尾的空格、制表符、全角空格 |
| 中文旁边的半角标点转全角 | 开 | `, . ; : ! ?` → `，。；：！？`；**只在中文旁边转**，`3.14`、`www.a.com`、`12:30`、`A.开端` 这类不动 |
| 直引号转中文弯引号 | 关 | `"…"` → `“…”`；**只在中文语境里转**，英文撇号（`don't`）、英文引语（`"Hi"`）、`他叫"Jack"` 这类不动 |
| 省略号 | 关 | 连续 3 个以上英文句点 → `……`；数字（`3.14`）、网址（`www.a.com`）里的点不动 |
| 删除中文之间的多余空格 | 关 | 可能改变语感，默认不勾 |

- **空一行（含缩进）**：空行里放两个全角空格（`　　`）。有些平台/软件会吃掉纯空行，粘过去就粘成一坨；带缩进的空行不会丢（口袋写作把这个叫「解决粘贴后丢失空行」）。
- **首尾空行不在「保持原样」的范围内**：源文开头的空行在整理时一律丢掉；结尾有一处换行就保留一个换行，连续多个尾随空行会被收成一个。这个行为对所有「段落之间」选项都相同（排版对话框里也有一句说明）。
- **引号 / 省略号两项默认关**：改了会动正文标点，所以不默认打开，由你在对话框里勾；勾选框旁边有说明，预览里会给出转换数量。
- 对话框里先看**预览和改动统计**（几段、缩进几段、删几处空白、转几个标点、转几个引号/省略号），确认后才套用；直接点「整理」则是**上来就整理**，结果用右下角提示告诉你这次的规则和改动统计。
- **整理 ≠ 保存**：结果只进编辑区，窗口标题 / 状态栏仍是**未保存**，按 `Ctrl+S` 才写盘——和本应用「完全手动保存」一致。
- **可撤销**：`Ctrl+Z`，或悬浮「整理」→「撤销上次整理（可撤销 N 步）」。撤销同样只是改编辑区，不会写盘；内存快照最多 50 步，关掉应用后不可撤销。
- **没有可改的地方就不动**：点「整理」时提示「本章已经是整理后的格式，没有可改的地方」（带这次的规则），正文一个字不动，撤销栈也不会多塞一步；对话框里「套用到本章」与实时预览面板用的是同一句结论（文案只从 `renderer/format-ui.js` 来，单测会拦「渲染层又自己拼一句」）。
- **只处理当前章**，不会碰别的章；章名、`书目.json` 一概不动。
- **光标不会乱跳**：整理/撤销后光标按原位置映射回同一段落，长章里接着写不会插到全章最前。
- 重复整理是安全的：已经整理过的正文再整理一次不会重复加缩进、不会重复转引号。

**整本一起整理：悬浮「整理」→「一键整理本书…」**（显式写盘动作，v0.4 起）

- 规则直接沿用点「整理」用的那套（也就是「排版设置…」里定下的规则），不用重新勾。
- 先做**预检查（只读）**：统计全书共几章、其中哪几章会被改动，一个字节都不写。
- 弹确认框，列清「规则、共几章、哪几章会改、写盘前会先备份」，点「开始整理」才真正执行。
- 写盘前把**要改动的原章节**复制到书内 `_trash\整理备份-时间戳\`；没改动的章既不备份也不重写（所以反复点也不会越备越多）。
- 逐章原子写盘，右下角显示「正在整理整本书：N/M 章」；整理完自动重载当前章、同步书架字数。
- **当前章有未保存修改会先问**：「保存后整理 / 不保存（按磁盘内容）/ 取消」。
- 已经是整理后格式的书再点一次**不会弹框**，只提示「没有可改的地方」。
- **整本整理不进「撤销上次整理」**：它是直接写盘的显式动作。要退回只能把 `_trash\整理备份-时间戳\` 里的 txt 手工拷回书文件夹（应用内还没有「一键还原整本整理」）。

**2. 正文显示（一字不动）** —— 「显示 ▾」→「显示：紧凑 / 标准 / 宽松」，或「设置」里细调：

| 项 | 可选值 |
|---|---|
| 正文字体 | 宋体 / 黑体 / 楷体 / **自定义字体文件**（.ttf / .otf / .ttc，选一次即可；只读取、不复制文件） |
| 字号 | 16–24 |
| 行间距 | 1.6 / 1.8 / 1.95 / 2.2 / 2.4 |
| 字间距 | 0 / 0.02 / 0.05 / 0.08 em |
| 左右边距 | 16–120 px |
| 正文宽度 | 通栏（默认），或 720 / 800 / 840 px 居中（840 ≈ 39.6 字，落在中文排版推荐的单行 17–40 字内；1.3.0 起 900 / 1000 下线，旧配置里的这两个值照常显示、不被改写） |
| 中西文自动间距 | 开（默认）/ 关；中文与英文 / 数字之间由系统自动留出细微间距，**只影响显示，不改正文、不进导出**（1.3.0） |
| 背景主题 | 原纸白 / 米黄（护眼）/ 豆绿（护眼）/ **夜间（深色）** / 牛皮纸（纹理）/ 网格纸（纹理） |

- 这些只改 CSS，**不写任何正文**；设置里改动会实时预览，点「取消」恢复原样，点「保存设置」才记住。
- **按书记忆**（v0.3 起）：书架右上「设置」改的是**全局默认**；在写作页里用「显示：紧凑 / 标准 / 宽松」、「正文显示设置…」或拖章节栏改的，只记在**当前这本书**上，换书会自动切回那本书自己的设置。写作页设置弹层底部有「恢复本书默认」，点了就回到全局。「显示 ▾」里的「不可见字符 / 超长段落提示」和「当前段落高亮」三个开关、**超长段落阈值**、以及高亮颜色也一样按书记住（只写 `config.json` 的 `bookDisplay`）。
- 自定义字体只记住文件路径：**换电脑或挪走字体文件后会自动退回宋体**，重新选一次即可。
- 夜间主题是新配的一套深色纸色 + 浅色墨色，不影响你的 txt。

> 说明：正文是纯文本 textarea，「视觉上的段首缩进」不能只靠 CSS 做，所以缩进是作为文本真的写进 txt 的（这也是导出/复制后仍然整齐的原因）。背景图片 / 背景特效 / 主题色 / 会员主题这些口袋写作里的附加项没有做（纯文本编辑器不需要，也避免往书库里塞图片文件）。
