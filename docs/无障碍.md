# 章回 · 无障碍说明

> 键盘可达性、焦点管理、点击目标尺寸与对比度的现状和自验方法。

## 无障碍（键盘 / 焦点 / 目标尺寸）



> 2026-11-08 · 1.3.0 起把无障碍从「只量对比度」扩到可执行的门禁。产品代码这一批**没有为此改动**（T8 只做工具侧），下面写清现在**已经做到什么**、**还差什么**、以及怎么自己验。



- **全部可交互元素都能键盘到达**：Tab 顺序 = 视觉顺序；书卡 / 章节列表 / 菜单 / 弹层各有方向键与 `Home` / `End`；`Esc` 收起弹层与菜单并把焦点还给打开它的元素；焦点环是 2px 朱红（只在 `:focus-visible` 出现，永不清除 outline）。章节排序的**拖动有键盘替代**：焦点在章节列表时 `Alt+↑` / `Alt+↓` 在本卷内挪一格（到卷边界再按一次跨卷；**1.4.0 起直接挪、10 秒内可在撤销条撤回**，不再弹确认框）——满足 WCAG 2.5.7。

- **2.5.8 目标尺寸（≥24×24）**：`node scripts/a11y-gate.js` 在真实窗口里量所有可点元素的盒子。当前实测 **635 条全部达标**：小于 24×24 的 36 条里，16 条走 WCAG 的「间距例外」（24px 圆不与相邻目标相交），20 条是**允许清单**里唯一的章节栏分隔条（5px 宽的拖拽条，加宽会遮挡编辑区边缘；B5 / A2 起它可聚焦并带完整键盘通道 —— ←/→ 步进、Shift 大步、Enter / 空格复位默认宽，属于 WCAG 2.5.8「尺寸是功能本身所必需」的例外；清单上限按每次状态扫描最多 1 条，20 条是多次状态 / 主题采样的合计，不是新增了同类小目标）。**1.4.0 起设置弹层按 5 个分区各扫一遍**（分区一次只显示一个，不扫就等于把其余分区的控件漏出判据）；顺带量出码字日历的翻月按钮只有 20×24，已补到 24×24（只补宽度，不改字号 / 颜色 / 间距）。

- **2.4.11 焦点不被遮挡**：门禁在 16 个弹层 / 面板状态里逐个聚焦（设置弹层按 5 个分区各扫一遍），检查焦点框有没有被视口、滚动容器或上层元素（弹层背景 / toast / 悬浮条）盖住。当前 190 条焦点全部合格（1.4.0 起含设置弹层的 5 个分区）。

- **对比度**：当前门禁口径是 **6 套主题 504 条规格全过 WCAG 2.1 AA，另有 12 条禁用态豁免**（`node scripts/contrast.js`；禁用态按 WCAG 1.4.3「inactive controls」豁免，只记录实测比值、不计失败）。**为什么还会看到「192/192」这个数字**：那是 v1.0 视觉优化发布时点的采样——6 主题 × 32 条规格（书架 11 / 写作页 20 / 启用态主按钮 1，未含 hover / active 与弹层内部）；后来对比度审计扩到 6 主题 × 86 条采样（84 条规格 + 2 条禁用态豁免 = 504 通过 + 12 豁免），192 与 504 不是同一套采样范围，两个数字都真实，看当前口径以 `node scripts/contrast.js` 的实测输出为准。APCA 只在门禁里当**影子参考**打印，不参与通过判定（APCA-W3 是非商业 Beta 许可，不内置进产品）。

- **3.3.7 不重复录入**（人工走查结论）：新建作品只问一次名字（标题就是文件夹名），导入小说时**不再追问书名**；作者 / 分组 / 标签只在「书籍信息」里填一次，之后导出 / 复制都沿用；导出范围（整本 / 按卷 / 按章）只问一次，不会在下一步再问一遍。

- **怎么自己验**：`node scripts/a11y-gate.js`（或 `pnpm run a11y`；`--static` 只跑静态、`--report` 只报告不报错）。它只读：书库与 userData 都在系统临时目录，跑完不会碰你的书架，默认书架目录（「文档」下的 `我的小说`）一个字节都不动。

- 还没做到的（已知边界）：菜单没有挂 `role="menu"` / `role="menuitem"`（见 [已知限制](已知限制.md) 里那条，是有意取舍，不是漏做）；书卡里套着「⋯」按钮的嵌套按钮语义仍是 1.4.0 之后的候选（目标尺寸已全部达标，允许清单为空）。
