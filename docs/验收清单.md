# 章回 / Chapterly v2.2.0 · 手工验收清单

> 用途：交付前照着点一遍，确认「能真用、不丢稿」。
> 预计耗时 15 分钟。建议用一个空的临时书架目录，不要动你的正式稿件。
> 自动化部分可先跑：`pnpm test`（3623 项）、`pnpm run e2e`（1946 项）、`node scripts/contrast.js`（504 条扩展态 + 12 条禁用态豁免；v1.0 发布时点是 6 主题 192/192，采样范围不同，见 [无障碍](无障碍.md)）、`node scripts/a11y-gate.js`（无障碍门禁二期：目标尺寸 / 焦点不被遮挡 / 主题令牌，真实 Electron + 临时书库）。
>
> **读者提示**：这是维护者的交付自测清单；普通用户请先看 [README](../README.md)，玩法见 [使用手册](使用手册.md)。

> 维护者文档（打包 / 构建供应链 / 静态闸门策略 / 红-绿锚点纪律）见 [维护与自检](维护与自检.md)。

## 准备

1. 在应用「设置」里把书架目录改到一个空的临时目录，例如 `D:\验收临时目录`。
2. 确认应用是新启动的、书架为空。

## 验收步骤

